# rj8228.github.io

Personal portfolio: a comic-book, web-slinger story set in Mumbai. Built with [Astro](https://astro.build), deployed to GitHub Pages at https://rj8228.github.io.

- Edit content in `src/data/profile.json`; theme colours live in `src/styles/global.css`.
- `npm run dev` for local development, `npm run build` to build to `dist/`.
- Every push to `main` deploys via `.github/workflows/deploy.yml`.
